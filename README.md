# empeo Inspector

Chrome extension ที่ทีม frontend ใช้ร่วมกัน สำหรับตรวจและควบคุมพฤติกรรมของ empeo ตอน runtime
ประกอบด้วย **lens** หลายตัว แต่ละตัวทำหน้าที่เดียว

> **สถานะ: prototype** — ส่องได้ + แกล้งจำนวนแถวได้
> แบบร่างเต็มอยู่ที่ [`docs/superpowers/specs/`](docs/superpowers/specs)

## ติดตั้ง

1. `git clone` เรโปนี้
2. เปิด `chrome://extensions` แล้วเปิด **Developer mode**
3. กด **Load unpacked** เลือกโฟลเดอร์ **`dist/`**
4. ปักหมุดไอคอน empeo Inspector ไว้บนแถบเครื่องมือ

`dist/` ถูก commit ไว้ในเรโป อัปเดตด้วย `git pull` อย่างเดียว ไม่ต้อง `npm install`

## ใช้ยังไง

กดไอคอน → **เปิดโหมดส่อง** popup จะปิดเอง จากนั้นใช้งานหน้าเว็บได้ตามปกติ

เอาเมาส์**ชี้**อะไรก็ได้บนหน้าจอ — ตาราง การ์ด รายการ — จะมีกรอบขึ้นพร้อมป้ายบอกว่า

```
praises/list · 11 แถว · 342 ms
[ ว่าง ]  [ 100 ]  [ 1000 ]
```

**ไม่ต้องรู้ชื่อ API มาก่อน** เครื่องมืออ่านข้อความในบริเวณที่ชี้ ไปเทียบกับ response ที่ผ่านตามา
แล้วบอกเองว่าข้อมูลตรงนั้นมาจากไหน

แค่ส่องดูเฉย ๆ ก็ได้ หรือกดปุ่มในป้ายเพื่อแกล้งเลย — กดแล้วหน้าเว็บโหลดใหม่เอง และกฎมีผลกับ
**เส้นนั้นเส้นเดียว** ไม่กระทบเมนู สิทธิ์ หรือการแจ้งเตือน

| ปุ่ม | ผล |
| --- | --- |
| `ว่าง` | รายการนั้นว่าง → เห็น empty state |
| `100` `1000` | วนซ้ำแถวจริงจนครบจำนวน → เห็นพฤติกรรมตอนข้อมูลเยอะ |
| `คืนค่า` | กลับไปใช้ข้อมูลจริง |

กด **ESC** ปิดโหมดส่อง · การคลิกบนหน้าเว็บยังทำงานปกติ โหมดส่องไม่ขวางการใช้แอป
มีแต่ปุ่มในป้ายที่เป็นของเครื่องมือ

ขอบสีส้มกับแถบด้านบนขึ้นตลอดเวลาที่มีกฎทำงานอยู่

**มีผลกับข้อมูลที่โหลดใหม่เท่านั้น** ถ้าแอป cache ไว้แล้วจะไม่เห็นอะไรเปลี่ยน

## Lens

| Lens | หน้าที่ | สถานะ |
| --- | --- | --- |
| **Chaos** | ดัด response ของ API ระหว่างทางกลับ | จำนวนแถวใช้ได้แล้ว · หน่วงเวลา ข้อผิดพลาด ข้อความยาว ยังไม่ทำ |
| **Micro-frontend** | เปลี่ยน `ma-*` remote ให้ชี้มาที่ dev server บนเครื่อง (ยกมาจาก `empeo-requestly`) | ยังไม่เริ่ม |
| **Stub** | จำลองเส้น API ที่หลังบ้านยังไม่ทำ | ยังไม่เริ่ม |

## ใช้ได้ที่ไหน

เครื่องมือทำงานเฉพาะโดเมนที่อยู่ในรายชื่ออนุญาตเท่านั้น:

- `localhost` ทุกพอร์ต (4200, 44399, 3000)
- `portal.dev.empeo.com`
- `portal.uat.empeo.com`

ระบบของลูกค้าจริงไม่อยู่ในรายชื่อ และจะไม่มีวันอยู่ — empeo เปิดให้ตั้งโดเมนเองต่อ tenant
การไล่แบนทีละโดเมนจึงรั่วเสมอ เราจึงอนุญาตเป็นรายชื่อแทน

## พัฒนา

```bash
npm install
npm run build      # หรือ npm run watch
npm test           # ชุดทดสอบของตัวแปลง JSON
npm run typecheck
```

หลังแก้โค้ดต้องกด **Reload** ที่การ์ดของส่วนขยายใน `chrome://extensions` **แล้วโหลดหน้าเว็บใหม่ด้วย**
เพราะ script ที่ฝังอยู่ในหน้าที่เปิดค้างไว้จะใช้ต่อไม่ได้

ถ้า **เพิ่ม permission ใหม่ใน `manifest.json`** การกด Reload ไม่พอ ต้อง **Remove แล้ว Load unpacked ใหม่**

## การเชื่อมต่อภายใน

ทุกอย่างวิ่งผ่าน `chrome.storage.local` กับ `window.postMessage` ทางเดียวเท่านั้น
ไม่มีการส่งคำถามแล้วรอคำตอบข้ามบริบท ไม่ใช้ `chrome.scripting` และขอ permission แค่ `storage`

```
popup ──storage.local──▶ bridge (isolated) ──postMessage──▶ chaos (MAIN)
      ◀──storage.local──          ◀──postMessage──
```

ตั้งใจให้เรียบง่ายระดับนี้เพราะช่องทางอื่นของ Chrome (message port, การฉีด script ตอน runtime,
permission ที่เพิ่มภายหลัง) ล้มเหลวไปแล้วทุกทางตอนสร้าง — ดูเหตุผลเต็มใน git log

`src/shared/transform.ts` เป็นฟังก์ชันล้วน ทดสอบได้โดยไม่ต้องมีเบราว์เซอร์ ส่วนที่เหลือต้องทดสอบ
ด้วยมือบน `portal.uat.empeo.com`
